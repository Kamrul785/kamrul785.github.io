# Kamrul Hasan | Academic Portfolio

A single-page academic portfolio built with React and Vite.

```powershell
npm.cmd install
npm.cmd run dev
```

Use `npm.cmd run lint` to check the source and `npm.cmd run build` to generate the production site in `dist/`.

Edit the portfolio content and Google Drive résumé link in `src/App.jsx`. The site styles are in `src/index.css`.
